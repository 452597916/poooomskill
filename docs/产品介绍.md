## 一、这是什么

你在 Claude Code、Trae CN、Codex 里装了越来越多的技能（SKILL.md），但很快会遇到三个问题：

1. **技能散落**：同一个技能可能装在好几个客户端里，谁装了什么、版本是否一致，没人说得清；
2. **名字记不住**：技能名是英文的、还经常很长（`trae-remote-official:deep-research-assistant:research-guide`），
   日常根本叫不出来；
3. **不知道谁真在用**：装了不等于在用，哪些技能真正被调用过、用了多少次，没有数据。

**PoooomSkill 就是为这三件事做的本地工具**：

- **扫得全**：一次扫描本机所有客户端目录，按技能真名归并副本，重复安装一目了然；
- **叫得动**：给技能起一个中文备注名，之后在 agent 里用 **暗号**、**斜杠短码** 或 **中文自然语言**
  点名调用，工具负责把它翻译成真实技能名；
- **数得清**：真实调用次数与频率（不是安装量），哪家客户端用的、什么时间用的，全都记账。

它**不做什么**：不联网、不上传任何数据、不修改技能内容、不替代任何客户端——
它只是你电脑上的一个"技能通讯录 + 接线员 + 电表"。

## 四、怎么用（三步上手）

### 1）安装并启动

- 下载安装包（GitHub Releases 里的 `PoooomSkill-Setup-x.x.x-x64.exe`），双击即可；
- **按用户安装**到 `%LOCALAPPDATA%\Programs\PoooomSkill`，不需要管理员权限、不弹 UAC；
- 单实例运行：重复双击只会把已有窗口调到前台；**关闭窗口 = 收起到右下角托盘**，统计继续记录；
- 可选「开机自动启动」，以 `--tray` 静默驻留托盘，不打扰你。

### 2）给技能填中文备注

打开「技能库」，对常用技能填三样东西：

- **中文备注名**（如「前端设计」）——调用时就用它；
- **一句话用法**（如「把页面重做一版」）——会写进别名表，agent 能参考语境；
- **分组**（如「设计」「调研」）——技能多了以后按组筛。

短命令会按拼音自动生成（「前端设计」→ `/ps-qdsj`），也可以手改。
填完点右上角「**生成并写入**」。

### 3）在 agent 里调用（三选一）

| 方式 | 怎么写 | 确定性 |
| --- | --- | --- |
| **暗号**（三家通用） | `【前端设计】帮我把这个页面重做一版` | 钩子程序识别，极高 |
| **斜杠短码**（Claude Code） | `/ps-qdsj 帮我…` | 程序解析，100% |
| **中文自然语言**（三家通用） | `用界面打磨帮我看看这个页面` | 取决于模型 |

一条消息可以点多个暗号：`先【界面规范查】审一遍，再用【深度调研】查同行做法`。
暗号符号可自定义（`【】《》「」：` 或自己填）。

**生效条件**：Trae CN 需重启一次；Codex 首次要在 `/hooks` 里点一次信任；Claude Code 热加载，改完即用。

### 界面速览（四个动作）

| 动作 | 位置 | 说明 |
| --- | --- | --- |
| **搜索** | 技能库顶部 | 支持中文名、拼音首字母（`qdsj`）、短命令（`sd-qdsj`）、真名、分组、描述 |
| **重新扫描** | 右上角 | **技能清单只在启动与手动重扫时更新**，平时不会反复扫描磁盘 |
| **生成并写入** | 右上角 | 把别名表、斜杠命令、钩子脚本写进各客户端（写入前自动备份） |
| **使用统计** | 顶部标签页 | 调用次数、按客户端分布、近 30 天趋势 |

## 五、为什么开源：这个工具需要社区

我们把 PoooomSkill 以 **MIT 许可**开源，理由有三条：

1. **它经手你的隐私边界**。这个工具要写你的 `~/.claude/settings.json`、`~/.trae-cn/hooks.json`，
   还要常驻后台。**只有代码公开可审计，"不联网、可撤销、写入前备份"这些承诺才值得相信**——
   你甚至可以自己从源码构建一份来用。
2. **它的价值来自"覆盖面"，而覆盖面只能靠社区**。AI 客户端在快速演进：
   今天适配 Claude Code / Trae CN / Codex，明天可能是 Cursor、Windsurf、Gemini CLI……
   新客户端的适配、新钩子方言、新平台（macOS / Linux），任何一个人都做不完。
3. **它是"基础设施"型的小工具**。统一的"中文名 → 真名"映射、可靠的调用计数，
   这类能力越多人用、越多人补，越可能成为跨客户端的事实标准——
   与其每人在自己机器上重复实现一遍，不如一起维护一份。

**关于许可**：MIT 允许自由使用、修改、再分发（含商用），只需保留版权与许可声明。
「PoooomSkill / 万智云集」的名称与 Logo 不在授权范围内，请勿用于衍生发行版的名义。

## 六、欢迎参与（需要什么样的帮助）

这个项目**门槛不高、可参与的面很宽**。以下方向都欢迎，从任何一条开始都可以：

| 想帮忙？ | 可以做什么 |
| --- | --- |
| **适配更多客户端** | Cursor、Windsurf、Gemini CLI、Qwen Code……按 `server/lib/config.mjs` 里的 `AGENTS` 结构加一份接入面即可 |
| **macOS / Linux 支持** | 启动器（现为 C#）、托盘、安装包、图标格式、数据目录等需要各自的实现 |
| **界面与交互** | 批量备注、导入/导出别名表、搜索增强、快捷键——React 组件层在 `src/`，样式统一走 cva |
| **文档与翻译** | 英文 README、截图、使用教程、录一段 1 分钟上手视频 |
| **测试与反馈** | 装完跑一遍 `npm run check -- --api`；遇到问题把 `launcher.log`、`poooomskill.log` 贴进 Issue |
| **不写代码也行** | 提需求、报 bug、分享你的用法、告诉朋友，都算贡献 |

**贡献流程**：

```text
Fork → 开分支 → 改代码 → npm run check -- --api 全绿 → 提 PR
```

CI（GitHub Actions）会在 Windows 上自动重跑类型检查、前端构建、全局自检与打包演练。
自检脚本会验证语法、产物生成、钩子行为（含"顿号不误触发"这类边界用例）与全部 HTTP 接口。

**排障入口**：`%APPDATA%\PoooomSkill\launcher.log`（启动器）与 `poooomskill.log`（服务）。

## 八、数据与隐私（再强调一次）

| 内容 | 位置 |
| --- | --- |
| 中文备注、分组、调用记录（SQLite） | `%APPDATA%\PoooomSkill\poooomskill.db` |
| 生成的产物（别名技能、命令、钩子、对照表） | `%APPDATA%\PoooomSkill\generated\` |
| 运行日志 | `%APPDATA%\PoooomSkill\*.log` |
| 写入第三方配置前的备份 | 同目录 `*.poooomskill-bak-*` |

- **不联网、不上传**：所有读写都发生在你自己电脑上；
- **可回滚**：「接入与同步 → 一键撤销全部」会完整清理写进各客户端的文件与钩子条目；
- **卸载保留数据**：卸载程序只清理程序与接入内容，你的备注与统计会留下。
