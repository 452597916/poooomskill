# PoooomSkill · 版本功能说明

> 本文档面向：
> - **用户** — 快速了解 PoooomSkill 各版本有哪些功能、能解决什么问题
> - **开发者** — 对照版本说明快速定位代码改动范围
> - **GitHub 访客** — 一眼看懂这个工具是干什么的、什么时候开始用合适

当前版本：**1.2.1**（2026-10-27）

---

## 核心定位（始终不变）

**本地 AI 技能管理台** — 把散落在各个 AI 客户端里的技能，用中文管起来、用中文调用、用数据说话。

它**不联网、不上传数据、不修改技能内容、不替代任何客户端**，只是你电脑上的一个"技能通讯录 + 接线员 + 电表"。

## CLI 与 MCP

```bash
# CLI（不开界面）
node server/cli.mjs list --named --limit 10
node server/cli.mjs find 前端
node server/cli.mjs code 头脑风暴      # 输出：/ps-tnfb
node server/cli.mjs trigger 头脑风暴   # 输出：【头脑风暴】
node server/cli.mjs stats              # 累计调用与热门技能
node server/cli.mjs tags | groups
```

MCP 接入（Claude Code / Cursor / Trae / Gemini CLI / Qwen Code 通用）：

```json
{
  "mcpServers": {
    "poooomskill": {
      "command": "node",
      "args": ["<安装目录>/server/mcp.mjs"]
    }
  }
}
```

工具：`list_skills`、`find_skill`、`get_skill`、`skill_stats`。

## 目录里有什么

| 路径 | 作用 |
|------|------|
| `src/` | 前端 React + TypeScript + Tailwind CSS 4 |
| `server/` | 本地 HTTP 服务（Node 22，无第三方运行时依赖）+ SQLite |
| `server/lib/config.mjs` | 客户端目录、产品信息、版本号 |
| `server/lib/store.mjs` | SQLite schema + CRUD |
| `server/lib/scan.mjs` | 扫描 SKILL.md、解析 frontmatter |
| `server/lib/pinyin.mjs` | 中文 → 拼音首字母 → `/ps-xxx` |
| `server/lib/generate.mjs` | 生成斜杠命令、别名技能、钩子脚本 |
| `server/lib/library.mjs` | 扫描结果 + 备注 + 标签的合并（服务端/CLI/MCP 共用） |
| `server/lib/diff.mjs` | 行级 diff（LCS），用于副本差异对比 |
| `server/cli.mjs` | 命令行工具（list / find / code / trigger / stats） |
| `server/mcp.mjs` | MCP stdio server（零依赖 JSON-RPC） |
| `build/make-icon.mjs` | 多尺寸 Windows 图标生成 |
| `brand/` | Logo 源文件（mark.svg = 完整旋窝、mark-small.svg = 圆+P） |

## 版本号规则

采用 [语义化版本](https://semver.org/lang/zh-CN/)：`MAJOR.MINOR.PATCH`

- **MAJOR** — 不兼容的 API 变更或架构重构
- **MINOR** — 新增功能、重要 UI 改进、客户端接入（v1.1 → v1.2）
- **PATCH** — bug 修复、小的视觉 tweak、内部重构（不影响外部）
